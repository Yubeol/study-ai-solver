# 2026-09-30 검색 평가 실행과 HTML 보고서

## 무엇을 만들었나
- **실제 평가용 질문 세트(33문항)**: 과목별로 1과목 8, 2과목 8, 3과목 10문항을 두고, 교재에 답이 없는 질문 7개를 더했습니다. 자료에 없는 7개 중 3개는 교재에 비슷한 주제가 있지만 답은 없는 "경계 사례"(LSTM, XGBoost, Mean Shift)입니다. Claude가 교재를 보고 초안을 쓴 뒤 수험생 말투로 바꿨고, 사용자가 검토했습니다. 파일은 `data/eval/questions.csv`이며 커밋하지 않습니다.
- **검색 평가 HTML 보고서**: 평가를 돌리면 질문마다 정답 쪽 페이지 썸네일, 검색 상위 5개 청크(점수·쪽·텍스트 앞부분)와 각 청크의 페이지 썸네일을 나란히 보여주는 HTML 파일이 자동으로 만들어집니다. 정답 쪽 청크 행은 노란색으로 표시되고, 위쪽 버튼으로 "틀린 것만"이나 "자료에 없음만" 골라 볼 수 있습니다.
- **평가 결과 기록과 기준 정리**: 답이 있는 26문항은 모두 상위 5개 안에 정답이 들었고, 1위 적중은 81%였습니다. 그러나 "자료에서 확인 불가"를 1위 점수 하나로 가를 수는 없다는 것이 확인됐습니다. 그래서 정답 쪽 기준(D-023)과 "확인 불가" 2단계 판단 설계를 문서로 정했습니다.

## 어떻게 돌아가나
1. `backend/app/retrieval/evaluate.py`의 `main`이 `data/eval/questions.csv`를 읽습니다. `parse_questions`가 형식을 검사합니다.
2. `run`이 질문 33개를 BGE-M3로 한꺼번에 벡터로 바꿉니다. 그다음 질문마다 `search.py`의 `search_theory`로 DB 뷰 `mingyu.v_searchable_theory`에서 가까운 청크 20개를 가져옵니다.
3. `find_rank`가 정답 과목 책의 정답 쪽 청크가 몇 위에 있는지 찾습니다. `summarize`가 hit@1·3·5, MRR, 임계값별 통과·차단 비율을 계산합니다.
4. 결과는 `data/reports/eval/{시각}.json`(질문별 상위 20개)과 `.txt`(요약)로 저장됩니다.
5. 이어서 `backend/app/retrieval/eval_report.py`의 `write_report`가 json을 읽습니다.
   - `collect`가 DB에서 청크 본문과 페이지 이미지 위치를 다시 조회합니다. json에는 청크 id만 들어 있습니다.
   - `Thumbnailer`는 `data/storage/`의 원본 페이지 이미지를 가로 320픽셀로 줄여 `data/reports/eval/thumbs/{page_id}.jpg`로 저장합니다. 이미 있으면 다시 만들지 않습니다.
   - `render_html`이 이 재료로 `{시각}.html`을 씁니다.
6. HTML 생성이 실패해도 json과 txt는 남습니다. 나중에 `eval_report`만 따로 실행해 다시 만들 수 있습니다.

DB는 읽기만 합니다. 교재 이미지가 들어간 보고서와 썸네일은 모두 `data/` 아래에 있어 커밋되지 않습니다.

## 이번 평가 결과 요약
- **설정**: BGE-M3 벡터 검색만 사용(리랭커·키워드 검색 없음), 상위 5개 기준
- **답이 있는 26문항**: 1위 적중 21개(81%), 3위 안 25개, 5위 안 26개(100%)
  - 3과목이 약해서 1위 적중이 6/10입니다.
- **1위 점수 범위**: 답이 있는 질문은 0.516~0.709, 자료에 없는 질문은 0.419~0.608로 겹칩니다.
  - 점수 기준을 0.55로 잡으면 자료에 없는 질문 6/7을 막지만, 답이 있는 질문 4개도 같이 막힙니다.
  - 그래서 기준값은 정하지 않았습니다.
- **1위를 못 한 5문항**:
  - a06: 이름이 없는 비슷한 쪽이 1위로 나왔습니다.
  - c01, c02, c09: 같은 단어가 다른 개념에도 쓰여서 엉뚱한 청크가 1위로 나왔습니다. 예를 들어 "군집추출"이 군집분석 청크로, "lift"가 향상도 곡선 청크로 끌려갔습니다.
  - c07: 답이 있는 p268 표가 한 줄로 뭉쳐 저장돼 순위가 낮았습니다.

## 정한 것
- **정답 쪽 기준(D-023)**: "그 쪽만 보고 질문에 답할 수 있으면 정답"으로 정했습니다. 이 기준으로 a06에는 p45를, c07에는 p271을 넣지 않았습니다.
  - a06은 이름을 묻는 질문인데 p45에 이름이 없습니다.
  - c07은 p271에 recall이라는 말이 없습니다.
- **"확인 불가" 2단계**:
  - 1단계: 임베딩 1위 점수가 아주 낮으면 LLM을 부르지 않고 바로 "확인 불가"로 답합니다.
  - 2단계: 애매한 구간은 리랭커 점수나 판정기로 판단합니다.
  - 두 단계의 값은 다음 세션에서 리랭커를 붙인 뒤 정합니다.
- **다음 작업 순서**: 질의 흐름 → 최소 화면(프론트) → 이론 보충·수정
