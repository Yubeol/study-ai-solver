이번 세션을 마무리한다. CLAUDE.md의 작업 완료 루틴을 따른다.
1. 관련 테스트를 실행하고 결과를 알려준다. 실패하면 커밋하지 말고 멈춘다.
2. docs/PROGRESS.md를 갱신한다.
   - "현재 상태"를 지금 기준으로 고쳐 쓴다.
   - "다음 작업"은 다음 세션이 이 문서만 보고 바로 시작할 수 있을 만큼 구체적으로 쓴다(할 일, 관련 파일, 주의할 점).
   - "완료 기록"에 오늘 한 일을 한 줄 추가한다.
3. 아키텍처가 바뀌었으면 docs/ARCHITECTURE.md, 중요한 결정이 있었으면 docs/DECISIONS.md(날짜, 이유, 외부 정보는 출처 URL)를 갱신한다.
4. docs/sessions/ 폴더에 이번 세션 설명을 새 파일로 만든다. 파일명은 날짜-주제(예: 2026-09-30-data-import.md). 기존 세션 파일은 읽지 않는다. 코드를 직접 짜지 않은 사람이 이해할 수 있게 쓴다.
   - 무엇을 만들었나: 기능 단위로 2~3문장
   - 어떻게 돌아가나: 요청이나 데이터가 어떤 파일의 어떤 함수를 거쳐 어디에 저장되는지 순서대로 서술형으로
   - 직접 확인하는 방법: 내가 실행해 볼 명령, 열어 볼 주소나 DataGrip에서 볼 테이블, 기대 결과
   - 아직 안 되는 것
   기능이 추가·변경됐으면 docs/MODIFY_GUIDE.md도 갱신한다.
5. 변경 파일 목록을 보여주고 커밋한다. push는 내가 요청할 때만 한다.
6. 마지막으로 세션 파일에 쓴 "직접 확인하는 방법"을 화면에 다시 보여주고 "이제 /clear 해도 됩니다"라고 알려준다.
